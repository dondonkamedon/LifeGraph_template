# LifeGraph Template

人生の出来事と幸福度の変化を記録する、ブラウザだけで動作するライフラインチャートです。

## できること

- チャートタイトル、生まれ年、対象年齢範囲の設定
- 詳細ライフラインイベントの追加・編集・削除
- イベントごとの幸福度（-20〜+20）の記録
- イベントを選択して、概要・理由・価値観などの詳細コメントを記入
- 一次情報イベント（誕生、入学、卒業、転職、結婚など）の記録
- 一次情報イベントの「プライベート／仕事」分類
- プラス／マイナス／中立イベントの縦点線表示
- 同年に発生したイベントのラベル自動調整
- グラフ上部への西暦表示
- グラフのPNG保存
- チャート全体のJSONエクスポート／インポート

## 使い方

1. `LifeGraph_template.html` をブラウザで開く
2. タイトル、生まれ年、対象年齢を入力する
3. 一次情報イベントと詳細ライフラインイベントを登録する
4. 必要に応じてJSONをエクスポートしてバックアップする

## データの扱い

入力データはブラウザのlocalStorageに保存されます。ファイル自体は書き換わりません。
別の端末やブラウザへ移行する場合は、JSONエクスポート／インポートを使用してください。
初期の生まれ年は空欄です。入力した個人情報やエクスポートしたJSONは公開リポジトリに追加しないでください。

## 公開前の確認

`python3 check_privacy.py` で、公開ファイルに連絡先や利用者固有のパスが混入していないか確認できます。変更を公開する前に実行してください。

## 作成の背景

人生の出来事を、幸福度の推移だけでなく、事実としての一次情報と、そこから得られた意味・価値観の詳細情報に分けて記録できるように設計しました。

単一HTMLで動作するため、サーバーや外部ライブラリを必要とせず、個人記録・研修・ワークショップなどに利用できます。
